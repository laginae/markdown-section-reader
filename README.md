# Markdown 目录与朗读 0.7.6

适用于 Qoder、Cursor 和 VS Code。支持章节导航、本节或从本节开始朗读，以及原文与“朗读预览”高亮。预览使用本地 KaTeX 和 Mermaid 渲染。

目录默认隐藏 H1–H6 标记，通过缩进和字重区分层级；悬停标题可查看级别和行号。在“朗读控制 → 朗读设置”中可重新启用标题层级标记。

## 本次更新

- 展开“实际读法预览（本地文字）”即可查看设置对函数、区间与表格的影响。预览只使用固定示例，不读取编辑器正文，不调用语音服务。播放进度刷新不再逐个更新目录标题。

- 新增默认开启的“每行重复表头”。关闭后，先读一次表头，再按行读数值；保留行号、空单元格位置和零值。智能略过大数字表与此开关独立，可从朗读设置或编辑器配置修改。
- 同步 Cozy 桌面版 1.7.8（`f7de1cb`）与朗读核心库 0.3.2（`18ffde5`）的公式和表格规则；不把修饰符擅自解释为平均值、上下界或导数，复杂公式继续受智能跳过规则保护。
- 在“朗读控制 → 朗读设置”直接选择公式读法、区间读法和简单函数读法。简单函数默认保留 of，可在简洁模式选择 `f x`；完整模式不变。修改读法后需重新开始朗读。
- 从 Obsidian 导入 Cozy 设置时，一并导入公式、简单函数与每行表头选项；不自动更换现有引擎、音色或密钥。
- 目录解析和纯文本朗读不再预先初始化 KaTeX；实际渲染公式时再加载。并发起读共享系统音色查询，过期起读在文本准备前退出。等待统计计入文本准备和音色查询，仍不能保证在线接口无等待。

在朗读预览正文中按空格可暂停／继续当前朗读，隐藏悬浮按钮后也可使用。焦点在按钮、链接、输入框或可编辑内容上时，空格保留控件原有行为；没有朗读会话时仍可用空格滚动页面。长按空格不会反复切换播放状态。

## 从选中位置开始朗读

在本插件的“朗读预览”中选中文字，右键选择“从选中位置开始朗读”，会从选区起点向后读到文档末尾。普通文字可精确到选区起点；公式与表格按完整对象处理。没有选区时，从右键点击的段落开头开始。

原生复制菜单继续保留；起点在打开菜单时保存，菜单夺取焦点后也可使用。朗读仍可通过空格、悬浮按钮和控制栏暂停／继续。高亮沿用对应的原文段落或对象；若文档已修改、预览已重绘或位置无法准确对齐，会提示重新选择。代码、Mermaid 和空白处不提供此朗读项。

## 双击启读与悬浮按钮

- 单击目录标题定位；双击目录标题或朗读预览中的标题，从该节开始读到文档末尾。
- 正文双击保留选词和提问引用行为。链接和其他操作控件不会触发双击启读。
- 朗读预览右下角的圆形按钮可从当前选定章节开始朗读。选定章节由点击目录或预览标题确定，悬浮按钮提示会显示该节标题。
- 播放时，圆形按钮切换为暂停/继续；将鼠标移到按钮上或用 Tab 聚焦，可展开停止及前后五秒按钮。窄屏触控设备会直接显示可用的控制。
- 在“朗读控制 → 朗读设置”中可分别关闭“双击标题从本节开始朗读”和“在朗读预览中显示悬浮按钮”。

从预览启读时，音频也在该预览中播放；控制栏与悬浮按钮共享同一个播放会话。首次点击会准备媒体播放，若宿主仍阻止自动播放，圆形按钮显示“播放朗读”，再点一次即可。关闭播放所在预览会停止朗读。IDE 普通源码编辑器和内置预览没有自定义悬浮按钮。

## Cozy 朗读能力

- 直接复用 Cozy Read Aloud 提交 `bf82c32` 的公式读法、文献引用、术语替换、语义断句、快启、缓冲规划与音频准备队列，以及核心库 0.3.1 的表格规则；来源和逐文件散列可核验。
- 简单公式自然转读，例如 `\frac{1}{2}` 读作“2 分之 1”。复杂公式可提示、尝试完整读出或略过。详读模式明确读出下标等结构；不保证任意 LaTeX 都能正确口述。
- 表格按列名和值朗读，支持智能略过大数字表、全部朗读或略过。关闭“每行重复表头”后，只在表格开头读一次列名，不改变智能跳过策略。
- 术语读法每行填写 `原词=读法`，例如 `CVaR=条件风险价值`。只改变朗读文本，不修改文件和引用。
- 连续播放按音频长度、倍速和近期合成耗时准备后续音频；最多三个未来片段、900 个朗读字符，最多两个同时合成请求。也可选择仅准备一段或按需生成。
- 快启先准备完整的开头句子，可选标准、快速或关闭。快速起播不保证后续一定没有等待。
- 音频在当前 IDE 进程内按引擎、音色、凭据身份和文本复用，有大小、数量和时间限制。无持久音频缓存，可以通过“清除本次运行的音频缓存”释放。
- 暂停、继续、停止、上/下一音频片段、前后五秒、实时倍速和音量。面板非输入控件获得焦点时，空格暂停，左右键移动五秒。
- 朗读控制可以收起，“朗读设置”默认折叠。

系统语音使用本机已安装的声音，MiMo 使用官方 `mimo-v2.5-tts`。系统音色的自然程度取决于已安装声音。MiMo 沿用 Cozy 的完整音频生成与提前合成机制，不把提前合成称为供应商流式播放。

## 使用

1. 从 [GitHub Releases](https://github.com/laginae/markdown-section-reader/releases/latest) 下载并安装 `markdown-section-reader-0.7.6.vsix`。已开启的窗口若仍使用旧版本，重载该窗口。
2. 打开 Markdown，通过活动栏书本图标或命令“Markdown 朗读：打开目录与朗读”进入。
3. 点击目录标题跳转，再点“只读本节”或“从本节开始”。本节包含子节，遇到下一个同级或更高级标题停止。
4. 打开“朗读预览”可查看公式、图表、目录定位及高亮。普通 IDE 内置预览没有本插件的选区工具和高亮桥接。
5. 要与 Obsidian Cozy 的音色和读法一致，点击朗读设置内的“导入 Cozy 设置”。Windows 上需保持 Obsidian、Cozy 运行并启用 Obsidian CLI。支持导入系统语音或 MiMo 的音色、倍速、音量、缓冲、公式、表格和术语设置。

MiMo 密钥从 Obsidian SecretStorage 读取并保存到当前 IDE 的 SecretStorage；Cursor 与 Qoder 分别保存。也可以单独点击“导入 MiMo”或执行“设置 MiMo 密钥”，随后选择 MiMo 引擎。

在线朗读将选定范围的处理后文本发送到小米官方接口。预取不会越过选定范围；停止或跳转不能撤回已经发送的请求，可能消耗对应额度。

## 预览中的聊天引用

- **复制提问引用**：复制路径、原文行号和实际选中文字。适合跨 IDE 或精确引用部分句子。公式与 Mermaid 按源码复制。
- **添加到 Cursor / Qoder 聊天**：调用宿主原生命令插入文件与行范围卡片。引用选区涉及的完整原文行，不能将卡片视为只包含渲染视图中的精确文字。Qoder 会临时定位源码选区、调用原生入口，再恢复预览标签。需要宿主聊天可用且已登录；命令返回不等于云端已收到内容。

两种入口均不会自动发送消息。通用格式示例：

```text
@docs/示例.md lines:7-8
选中内容：
> 这里保留实际选中的文字。
```

工作区内使用相对路径，工作区外使用完整路径。没有原生入口的宿主只显示复制按钮。不修改 IDE 安装文件，不依赖开发者工具粘贴脚本，不修改工作区信任。

## 高亮与播放边界

公式和术语会改变朗读文字，但原文偏移单独保留；高亮依据实际播放的音频片段对应的源段落或公式、表格块。一个片段可以对应多个短源块。MiMo 没有提供本实现可用的逐字时间戳，因此不宣称逐字精确高亮。

文件修改或切换后停止旧会话。暂存音频、停止后的异步响应及过期选区都经过会话校验。不完整生成或合成失败会停止并提示，不静默跳过；后台失败不会循环重试。

## 开发与验证

```text
npm ci
npm test
npm run package
```

`vendor/cozy-reading-provenance.json` 记录复用模块、完整核心库的源散列和依赖路径适配。许可证保存在 `vendor/licenses`。打包及本地安装核对报告生成在未公开的 `qa` 目录，不随源码发布。

需要同步上游时，先准备干净的 Cozy 源码提交，再执行 `node scripts/sync-cozy.cjs <Cozy源码目录>`；脚本只复制明确列出的 13 个朗读模块及其固定版本核心库，不读取笔记或插件设置。

本次以通用样例完成离线自动测试、打包与安装文件核对；没有在线合成、导入真实密钥或重复执行 IDE 整套交互验收。
