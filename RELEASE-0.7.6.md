# Markdown Section Reader 0.7.6

- The reading settings panel previews fixed academic samples through the actual Markdown reading plan. It does not read the active file, synthesize audio or use a key.
- Regular playback updates keep the outline in place. Only the previous and new selection are restyled; heading levels update only when needed.
- Bundles the verified public desktop 1.7.8 and Core 0.3.2 snapshots. Install the VSIX in Qoder or VS Code; reload an already open window when convenient.
